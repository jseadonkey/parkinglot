GeoJSON and future vendor-specific loaders. Maps properties into the shared parcel schema consumed by scoring.

Property hints (GeoJSON `properties`):

- `APN` or `apn`
- `COUNTY_FIPS` or `county_fips`
- `LOT_SQFT` / `lot_sqft`
- `ZONING` / `zoning_code`
- `ZONING_ALLOWS_SURFACE_PARKING` (bool)
- `IS_CORNER` (bool)
- `DIST_DEMAND_M` (float, meters)
